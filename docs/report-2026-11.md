## 핵심 발견

### 1. "빈틈"은 몇 달 안에 채워지지만, 채운 앱들이 크지 못한다

검색 상위 10개 앱 중 최근 1년 안에 나온 앱의 비율:

| 키워드 | 신규 앱 | 신규 앱 설치 수(중앙값) | 기존 앱 설치 수(중앙값) |
|---|---|---|---|
| 냉장고 / 냉장고 관리 | 6/10, 5/10 | 100 | 5만 / 1천 |
| 이유식계산기 / 이유식식단표 | 5/10 | 500 | 10만 / 1만 |
| 유아식단표 | 5/10 | 500 | 10만 |
| 레시피북 | 4/10 | 1천 | 100만 |
| 육아휴직계산기 | 2/10 | 100 | 10만 |
| 어린이집 입소맵 | 3/10 | 10 | 100만 |

- "수요는 있는데 공급이 약한 키워드"마다 2026년에 나온 1인 개발 앱이 3~6개씩 들어와 있어요. 대부분 설치 수가 1천 회 이하예요.
- 데이터로 찾을 수 있는 빈틈은 남들도 같은 방법으로 찾고, AI 코딩 도구 덕에 금방 만들어요. 그런데 아무도 크지 못해요. 막히는 지점은 만드는 게 아니라 **사람을 데려오는 것**이에요.
- 그래서 "공급이 적은 곳을 찾는다"는 접근은 앱에서 그대로 쓰면 약해요. 빈틈을 찾았다면 "그 사람들을 내가 데려올 수 있나?"까지 답할 수 있어야 해요.

### 2. 육아: 돈은 위치추적·사진에서, 불만은 정부 앱에서

**돈이 되는 곳(매출 Top 16)**
- 위치추적·자녀 폰 관리 9개, 사진·앨범 3개, 작명 3개, 열나요 1개.
- 위치추적 쪽은 Find my kids(5천만+) 같은 글로벌 앱이 장악했고, 저평점 비율이 56.8%로 대부분 결제 불만이에요. 개인정보 문제까지 있어서 들어가기 어려워요.

**이미 잘 채워진 곳**
- 육아기록: 베이비타임 ★4.94, 저평점 3.4%
- 사진 공유: 쑥쑥찰칵 ★4.87
- 1등이 강하고 만족도도 높아서 빈틈이 없어요.

**불만이 가장 큰 곳**
- 아이사랑 모바일(교육부): 설치 100만+, ★1.4, 최근 리뷰 저평점 비율 97.7%.
- 불만 내용
  - 어린이집 입소대기 신청이 앱, 웹, PC를 오가며 반복돼요.
  - 보육료를 결제할 때 공동인증서를 요구해요.
  - 시간제보육 예약이 성공했는데 나중에 사라져 있어요.
- 다만 신청 자체는 공식 시스템에서만 할 수 있어서, 앱을 대체하는 게 아니라 **절차를 안내하는 쪽**이 기회예요.
- 마미톡도 저평점 52~64%인데, 광고와 반강제 결제, 업데이트 후 퇴보가 주된 불만이에요.

### 3. 음식 및 음료: 무료 순위는 O2O 판, 돈은 "SNS 레시피 저장"에

- 무료 Top 30은 배달 플랫폼과 프랜차이즈 주문 앱이 차지하고 있어요. 개인이 들어갈 곳이 아니에요. 프랜차이즈 앱은 저평점 비율이 71.7%로 높지만 해결할 수 있는 영역이 아니에요.
- App Store 매출 순위를 보면 국내 앱 중에서는 **SNS 영상을 레시피로 정리해 주는 앱**이 돈을 벌고 있어요.
  - 해먹으리 3위
  - CookGo 7위 (Google Play 10만+, 출시 1년 4개월)
  - 냠냠쩝쩝 레시피북 14위
- 음식 카테고리에서 지불 신호와 성장 증거가 둘 다 있는 유일한 니치예요. 다만 매출 상위권에 평가가 7~100개뿐인 앱도 있어서, 진입 문턱은 낮고 전체 시장 규모는 작아요.
- 냉장고·식비·식단 앱은 요청 리뷰 비율이 20~45%로 사용자 참여는 높아요. 하지만 앱마다 설치 수가 작아요.
- 기능 요청이 서로 교차해요.
  - 레시피 저장 앱 사용자는 냉장고 재고 기능을 원해요.
  - 냉장고 앱 사용자는 레시피 추천을 원해요.
  - 냉장고 파먹기 앱 사용자는 장보기 목록과 식단짜기를 원해요.
- 지금은 따로 노는 기능들을 하나로 묶어 달라는 수요가 반복해서 보여요.
- 만개의레시피는 저평점 10%로 1등 자리가 안정적이에요.

## 이전 판단과 달라진 점

| 이전 판단 (공개 자료 기반) | 데이터로 확인한 결과 |
|---|---|
| 육아 "계산·결정 도구"는 비어 보임 | 비어 있지 않음. 육아휴직 계산기·이유식 계산기에 2026년 신규 앱이 여럿 있음. 다만 다 작음(설치 100~1천). |
| 레시피 서비스는 식비·장보기 쪽으로 좁히기 | 식비·냉장고 니치는 신규 앱이 몰리고 아무도 못 큼. 지불 증거는 "SNS 레시피 저장"에 있음. |
| 육아 × 금융이 1순위 | 유효하지만 스토어 앱이 아니라 **검색 유입을 받는 웹**이어야 함. 같은 기능을 앱으로 낸 경쟁자들이 스토어에서 못 크고 있음. |

## 추천

**1순위: 육아 행정·돈 가이드 (웹 우선)**
- 다루는 내용: 어린이집 입소대기, 보육료·시간제보육, 육아휴직 급여, 지원금 계산
- 수요: 자동완성에 "어린이집 입소대기", "입소맵", "육아휴직급여신청", "육아휴직계산기"가 떠요.
- 불만: 공식 앱에 대한 불만이 극심해요(★1.4, 설치 100만+).
- 경쟁: 스토어 앱들은 설치 100회 수준이에요. 사용자는 스토어가 아니라 네이버로 검색해요.
- 유입 통로: 아내분 블로그 독자층과 그대로 겹쳐요.
- 수익: 광고·제휴 위주라 지불 신호는 약해요. 트래픽을 모은 뒤 수익화하는 구조예요.

**2순위: SNS 레시피 저장 + 냉장고 재고 + 장보기 연결**
- 지불: App Store 매출 상위에 실제로 올라 있어요.
- 차별점: 여러 앱에 흩어진 기능 요청을 하나로 묶을 여지가 있어요.
- 위험: 같은 아이디어의 신규 앱이 늘고 있어요(최근 1년 4개). 유입 통로가 없으면 1번 발견의 함정에 그대로 빠져요.

**피할 곳**
- 위치추적·자녀 폰 관리, 사진·앨범, 육아기록, 배달·프랜차이즈 주문.

## 한계와 다음 단계

- **검색량 미측정**: 네이버 검색광고 API(키워드 도구)로 월간 검색량을 받으면 1순위 주제들의 크기를 비교할 수 있어요. API 키 발급과 `api.searchad.naver.com` 허용이 필요해요.
- **리뷰 시점 편향**: 리뷰는 앱당 최신 400~600건이라 최근 업데이트 이슈가 과대 반영됐을 수 있어요.
- **매출 순위 누락**: Google Play 음식 카테고리 매출 순위가 빠져 있어요.
- **설치 수 해상도**: 설치 수는 스토어가 구간(1천+, 1만+…)으로만 공개해요.

## 재현

```bash
npm install
npm run collect        # 순위·상세·리뷰·키워드 수집 → data/raw
npm run collect:niche  # 니치 키워드 상위 앱 리뷰 추가 수집
npm run analyze        # data/analysis/*.json + 콘솔 요약
npx tsx src/newcomers.ts
```
